# Месители: Финал — Серия первая

Комедийная визуальная новелла с мини-играми. Одним файлом, без установки.

## Играть

Открыть `index.html` в браузере. Рядом должны лежать папки `art`, `mus` и `vo` — в них картинки, музыка и озвучка.

## Выложить на GitHub Pages

1. Создать репозиторий и загрузить туда всё содержимое этой папки: `index.html`, `.nojekyll`, `README.md` и папки `art`, `mus`, `vo`.
2. В настройках репозитория открыть **Settings → Pages**.
3. В **Source** выбрать ветку `main` и папку `/ (root)`, сохранить.
4. Через минуту игра будет доступна по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

Файл `.nojekyll` нужен обязательно — без него GitHub Pages может резать содержимое.

## Что внутри

- 74 сцены, 4 мини-игры, 2 ветки прохождения
- 217 иллюстраций, 11 музыкальных треков, 101 озвученная реплика
- Прогресс сохраняется в браузере

## Управление

В сценах — кнопки на экране. В забеге и погоне — стрелки или свайпы. Реплики звучат сами, кнопка «Дальше» доступна сразу и обрывает запись.
